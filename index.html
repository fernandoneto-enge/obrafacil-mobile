Seus dados e backups

Antes de atualizar: use ⬇ Exportar backup JSON no aplicativo antigo. A versão nova conserva a chave de dados obrafacil_v1, mas o armazenamento pode mudar conforme pasta/endereço/navegador. Se os cadastros não aparecerem aqui, importe o backup em Dados. Importar substitui os dados atuais — faça backup antes.

Os registros ficam salvos localmente no navegador, mas podem ser perdidos se você limpar os dados do navegador ou usar outro aparelho.

Manutenção

A limpeza remove todos os cadastros deste navegador. Exporte um backup antes.

Como este app funciona?

HTML organiza as telas. CSS cuida do visual. JavaScript valida, calcula e salva os dados usando localStorage.

As fotos são reduzidas e salvas junto aos RDOs neste navegador e no backup JSON. Este protótipo não possui login, servidor, sincronização entre aparelhos nem controle oficial de ponto. O relatório usa impressão do navegador (escolha Salvar como PDF).
